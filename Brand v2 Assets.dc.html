05

提交步骤

我没有向仓库写入的权限，所以最后一步需要你来跑。先从项目里下载 brand-v2/：

git checkout -b brand/v2

# 覆盖到仓库根目录（brand-v2/ 的结构与仓库一致）
cp -R brand-v2/. .
rm CHANGELOG-entry.md            # 内容先贴进 CHANGELOG.md 顶部

pnpm install --frozen-lockfile
pnpm build:docs                  # 重新生成 docs/palette.json
pnpm verify

git add -A
git commit -m "feat!: rebuild symbol geometry, complete the token system, add type tokens"
git push -u origin brand/v2

合并后按仓库的发布流程打标签：pnpm release 2.0.0，再 git push origin v2.0.0 触发 release workflow。
